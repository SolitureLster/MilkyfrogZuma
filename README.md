## 1. 项目简介

Tsuma 是一个 TypeScript + Canvas 实现的球链消除游戏（玩法参照 Zuma / 祖玛）：
玩家控制一个「奶娃」造型的发射器，把彩色球射进沿路径移动的球链，三个及以上同色球相连即消除；
球链走到路径尽头的洞，本局结束。

演示版在保留原有玩法内核的前提下，做了四件事：

1. **锁定单关**：进入即玩 `1-1 Spiral`，不能选关，通关也不会跳到下一关。
2. **补齐结束状态**：胜负都会冻结球链与输入，并弹出结算。
3. **极简结算/重试**：显示本局得分，点击「再来一局」复用原重置逻辑重开本关。
4. **自定义发射器**：奶娃贴图随鼠标朝向旋转，嘴部色球同步转动。

### 1.1 视觉表现（在原始项目基础上新增）

- **奶娃发射器**：用奶娃形象（`public/image/milkyfrog.jpg`）替代原来的圆形炮台。
  整张贴图以发射点为中心，跟随鼠标方向**实时旋转**（`src/renderer.ts` 的 `renderLauncher`）。
- **嘴部色球**：当前待发射的彩色球按瞄准方向偏移绘制在奶娃嘴部，
  随朝向绕发射点**一起转动**，形成"奶娃含着球瞄准"的效果。
- **瞄准指示线**：从奶娃嘴部沿瞄准方向延伸，辅助判断出球方向。
- **降级兜底**：贴图尚未加载完成时，自动退回为圆形色球，保证不影响可玩性。

## 2. 快速开始

```bash
cd zuma-demo
pnpm install
pnpm dev
```

- 开发地址：<http://localhost:5173/MilkyfrogZuma/>（`vite.config.ts` 的 `base` 为 `/MilkyfrogZuma/`，路径不能省）
- 构建：`pnpm build`
- 测试：`pnpm test`

### 2.1 部署（GitHub Pages）

推送到 `main` 后，`.github/workflows/deploy.yml` 会自动执行「安装 → 测试 → 构建 → 发布」，
站点地址：<https://soliturelster.github.io/MilkyfrogZuma/>。

首次启用需要在仓库 **Settings → Pages** 中把 Source 设为 **GitHub Actions**。

## 3. 玩法

| 操作 | 说明 |
|---|---|
| 移动鼠标 | 调整瞄准方向：奶娃贴图、嘴部色球、瞄准线一起旋转 |
| 点击画布 | 发射奶娃嘴部当前颜色的球 |
| 三个及以上同色相连 | 消除，计入本局得分 |
| 球链走到洞 | 本局失败，球链与输入立即冻结 |
| 清空全部球 | 本局通关 |
| 点击「再来一局」 | 重开当前关卡，分数归零 |

## 4. 能力边界

### 4.1 已实现并纳入验收

- 单关卡 `board11`（1-1 Spiral，30 球，4 色）（`src/boards/board11.ts`）
- 奶娃发射器：贴图随鼠标朝向旋转，嘴部色球同步转动（`src/renderer.ts` `renderLauncher`）
- 发射、碰撞、三消、补球、颜色收敛
- 胜负判定与**终态冻结**（`src/game.ts`）
- 本局得分（消除球数，含爆炸波及）
- 结算遮罩 + 「再来一局」（`index.html` / `src/main.ts`）
- 复用原重置逻辑的重开（`restartGame`）
- 音效开关（左上角 🔊/🔇）与整体音频调优：16-bit 采样、低通柔化、高频音触发节流；结束时不播放音效

### 4.2 代码保留但未纳入验收

- 道具效果：瞄准、减速、回退、爆炸（`src/game.ts` 的 `newBallEffect`）
- 程序化音效（`src/sounds.ts`）
- 调试能力：`?debug`、`?controls`、`?mapEditMode`
- 其余 50+ 关卡定义（`src/boards/`，演示版不会进入）

### 4.3 延期项（不在本次交付范围）

## 5. 项目结构

```
zuma-demo/
├── index.html              # 页面骨架 + 结算遮罩 DOM
├── public/                 # 静态资源（青蛙贴图等）
├── docs/
│   ├── 01-调用链定位报告.md
│   └── 提交说明.md
├── src/
│   ├── main.ts             # 启动、主循环、结算遮罩联动
│   ├── game.ts             # 核心状态机：发射、步进、终态、重开
│   ├── renderer.ts         # Canvas 渲染
│   ├── interface.ts        # 鼠标输入
│   ├── match.ts            # 三消判定与计分
│   ├── collision/          # 碰撞检测
│   ├── movement/           # 球链移动
│   ├── boards/             # 关卡定义
│   ├── path.ts / util.ts   # 路径生成与工具函数
│   └── linkedList.ts       # 球链双向链表
└── vite.config.ts
```

## 6. 技术栈

- Vitest（单元测试）
- 无后端、无持久化
