## 1. 玩法与设计

Milkyfrog Zuma 是一个 TypeScript + Canvas 实现的球链消除游戏（玩法参照 Zuma / 祖玛）：
玩家控制一只「奶娃」，把彩色球射进沿路径移动的球链，三个及以上同色球相连即消除；
球链走到路径尽头的洞，本局结束。

小组在保留原玩法内核（球链运动、碰撞检测、三消判定）的前提下，重新设计了外层体验：

1. **一关到底**：进入即玩 `1-1 Spiral`，不设选关，通关也不跳关。
2. **结束即冻结**：胜负判定的瞬间锁死球链与输入，不再"自动重开后玩家才发现已经输了"。
3. **结算与重试**：显示本局得分，点击「再来一局」复用原重置逻辑重开本关。
4. **奶娃发射器**：贴图随鼠标朝向旋转，嘴部色球同步转动。
5. **音频反馈**：重新调参消除刺耳感，并提供静音开关。
6. **可部署**：一条 CI 流水线完成测试、构建与 GitHub Pages 发布。

### 1.1 小组的改动清单（相对原始玩法内核）

| 模块 | 我们做了什么 | 代码位置 |
|---|---|---|
| 视觉/交互 | 奶娃贴图随瞄准实时旋转，嘴部色球与瞄准线同步 | `src/renderer.ts` `renderLauncher` |
| 状态机 | 新增终态守卫：结束后冻结 `step()`、球链与发射 | `src/game.ts` `step()` |
| 结算闭环 | 计分展示 + 胜负遮罩 + 「再来一局」 | `src/main.ts`、`index.html` |
| 计分 | 消除数量统计（含爆炸波及）由 `resolveMatches` 回传 | `src/match.ts`、`src/game.ts` |
| 重试 | 抽出 `restartGame()`，复用原 `resetBoard` 逻辑 | `src/game.ts` `restartGame` |
| 音频 | 16-bit 采样、低通柔化、触发节流、静音开关、移除结束音效 | `src/sounds.ts`、`src/main.ts` |
| 工程化 | 调用链报告、能力边界、CI/CD 部署 | `docs/`、`.github/workflows/deploy.yml` |

### 1.2 原创视觉：奶娃发射器

- **奶娃贴图**：用奶娃形象（`public/image/milkyfrog.jpg`）替代原来的圆形炮台。
  整张贴图以发射点为中心，跟随鼠标方向**实时旋转**。
- **嘴部色球**：当前待发射的彩色球按瞄准方向偏移绘制在奶娃嘴部，
  随朝向绕发射点**一起转动**，形成"奶娃含着球瞄准"的效果。
- **瞄准指示线**：从奶娃嘴部沿瞄准方向延伸，辅助判断出球方向。
- **降级兜底**：贴图尚未加载完成时自动退回圆形色球，不影响可玩性。

### 1.3 关键设计取舍

- **结算用 DOM 遮罩而非画布文字**：按钮天然可点击、可聚焦，也避免把 UI 状态写进渲染循环。
- **重试复用 `resetBoard` 而非重建 `Game`**：事件系统与音效管理器只注册一次，避免监听器泄漏。
- **结束选择"冻结"而非"自动重开"**：让玩家先看到结果，再决定是否继续，符合"结束 → 结算 → 重试"的闭环。
- **音频用 16-bit + 低通 + 节流**：jsfxr 的 8-bit 合成在高频触发下会产生量化毛刺和叠音，这是刺耳感的根因。

## 2. 快速开始

```bash
cd zuma-demo
pnpm install
pnpm dev
```

- 开发地址：<http://localhost:5173/MilkyfrogZuma/>（`vite.config.ts` 的 `base` 为 `/MilkyfrogZuma/`，路径不能省）
- 构建：`pnpm build`
- 测试：`pnpm test`

### 2.1 部署（GitHub Pages）

推送到 `main` 后，`.github/workflows/deploy.yml` 会自动执行「安装 → 测试 → 构建 → 发布」，
站点地址：<https://soliturelster.github.io/MilkyfrogZuma/>。

本仓库已把 Pages 的 Source 配置为 **GitHub Actions**，无需手工操作。

## 3. 玩法

| 操作 | 说明 |
|---|---|
| 移动鼠标 | 调整瞄准方向：奶娃贴图、嘴部色球、瞄准线一起旋转 |
| 点击画布 | 发射奶娃嘴部当前颜色的球 |
| 三个及以上同色相连 | 消除，计入本局得分 |
| 球链走到洞 | 本局失败，球链与输入立即冻结 |
| 清空全部球 | 本局通关 |
| 点击「再来一局」 | 重开当前关卡，分数归零 |

## 4. 能力边界

### 4.1 小组实现并纳入验收

- 奶娃发射器：贴图随鼠标朝向旋转，嘴部色球同步转动（`src/renderer.ts` `renderLauncher`）
- 单关卡 `board11`（1-1 Spiral，30 球，4 色）的完整可玩闭环
- 胜负判定与**终态冻结**（`src/game.ts`）
- 本局得分（消除球数，含爆炸波及）
- 结算遮罩 + 「再来一局」（`index.html` / `src/main.ts`）
- 复用原重置逻辑的重开（`restartGame`）
- 音效开关（左上角 🔊/🔇）与整体音频调优；结束时不播放音效
- CI/CD：推送到 `main` 自动测试、构建并发布到 GitHub Pages

### 4.2 原始内核保留（未改动或仅做适配）

- 球链运动、碰撞检测、路径生成本体（`src/movement/`、`src/collision/`、`src/path.ts`）
- 三消判定的基础算法（`src/match.ts`，我们只追加了消除计数的回传）
- 50+ 关卡定义（`src/boards/`，演示版只启用 `board11`）
- 道具效果：瞄准、减速、回退、爆炸（代码保留，未纳入本次验收）
- 调试能力：`?debug`、`?controls`、`?mapEditMode`

## 5. 项目结构

```
MilkyfrogZuma/
├── index.html              # 页面骨架 + 结算遮罩 DOM
├── public/                 # 静态资源（奶娃贴图等）
├── docs/
│   ├── 01-调用链定位报告.md
│   └── 提交说明.md
├── src/
│   ├── main.ts             # 启动、主循环、结算遮罩、音效开关
│   ├── game.ts             # 核心状态机：发射、步进、终态、重开
│   ├── renderer.ts         # Canvas 渲染（含奶娃发射器）
│   ├── interface.ts        # 鼠标输入
│   ├── match.ts            # 三消判定与计分
│   ├── sounds.ts           # 音频参数与播放节流
│   ├── collision/          # 碰撞检测
│   ├── movement/           # 球链移动
│   ├── boards/             # 关卡定义
│   ├── path.ts / util.ts   # 路径生成与工具函数
│   └── linkedList.ts       # 球链双向链表
├── .github/workflows/      # Pages 部署流水线
├── ATTRIBUTION.md
└── vite.config.ts
```
