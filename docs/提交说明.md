## 1. 一句话说明

在开源祖玛类游戏 [jamiely/tsuma](https://github.com/jamiely/tsuma) 的基础上，锁定单一关卡
`board11`，补齐"游戏结束"终态守卫与极简结算/重试，并裁剪文档中超出实际能力的承诺，
形成一个**可直接进入、可结束、可重玩**的演示原型。

> 注：奶娃发射器（贴图随鼠标朝向旋转、嘴部色球同步转动）是本小组在本次迭代前已完成、
> 已包含在项目快照中的视觉改造，本次未改动该部分；说明见 `README.md` §1.1。

### 4.1 人工验收步骤

1. `cd zuma-demo && pnpm install && pnpm dev`
2. 打开 <http://localhost:5173/tsuma/> —— 应**直接进入 1-1 Spiral**，无选关界面。
3. 发射若干球，等球链走到洞 —— 本局立即结束，弹出「游戏结束 + 本局得分」。
4. 结束后继续点击画布 —— **不应再发射新球，球链不再移动**。
5. 点击「再来一局」—— 同一关重开，分数归零。
6. 若想验证通关：把 `src/boards/board11.ts` 的 `ballCount` 临时改为 `1` 再玩一局，
   应显示「通关！」且仍停留在 1-1（不跳 1-2）。
7. 点左上角 🔊 —— 可静音/恢复，偏好会被记住；连续碰撞时不应再叠成刺耳的噪音。

## 7. 已知限制

1. **仅一个关卡**：`board11`，30 球，一局约 3–5 分钟。
2. **分数口径简单**：只统计消除球数（含爆炸波及），无连击、时间、剩余球奖励。
3. **结算无动画**：直接以遮罩覆盖画面，球链停在结束瞬间。
4. **无持久化**：刷新即重新开始，不记录最高分。
5. **上游遗留 bug 未处理**：见 `TODO.md` 第 4、8 条（球链边界问题）。
6. **构建路径固定**：`base: '/tsuma'`，部署到根路径需改配置。
7. **音效为主观调参**：已按"16-bit + 低通 + 降音量 + 触发节流"整体柔化，但音色好坏需人工试听；不满意可直接用左上角开关静音。
